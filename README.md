# 👟 SoleHub — Online Footwear & Sneaker Store

**SoleHub** is a modern, responsive e-commerce web platform designed for showcasing and purchasing footwear and sneakers. Built using HTML5, modern CSS3 styling, and JavaScript, it offers an interactive online shopping experience with smooth animations, rich carousels, and an intuitive user interface.

---

### 🚀 Key Features

- **Dynamic Homepage:** Interactive hero sliders and 3D coverflow carousels powered by Swiper.js.
- **Detailed Product Pages:** Multi-angle image previews, size selections, and real-time order summaries.
- **Shopping Cart & Checkout:** Add-to-cart functionality, cart item management, and an organized checkout workflow.
- **User Authentication UI:** Sleek modal dialogs for Sign In and Registration with client-side form validation.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile devices using Bootstrap 5 and custom media queries.
- **Dedicated Pages:** About Us, Contact Us, FAQ Accordions, and Promotional/Sale sections.

---

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Frameworks & Libraries:** Bootstrap 5, Swiper.js, Owl Carousel, UIKit
- **Icons & Fonts:** Font Awesome, Boxicons, Google Fonts (Playfair Display, Karla, Lora)
- **Deployment:** Firebase Hosting ready
